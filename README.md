# لوحة الأفكار والمبادرات — كِفّة

لوحة مبسّطة لفريق التسويق في كِفّة للقهوة المختصة: تسجيل نقاط المشاركة
لكل موظفة، مع تفاصيل الفكرة وتاريخها، ترتيب مباشر للمتصدرات، فلترة
بالاسم وبالنطاق الزمني، وتصدير تقرير.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | **الملف الجاهز.** صفحة واحدة مكتفية بذاتها — الخطوط والشعار مدمجة بداخلها، لا تحتاج إنترنت. |
| `app.template.html` | المصدر الذي تُحرَّر فيه التعديلات (بدون الخطوط). |
| `build.py` | يدمج الخطوط والشعار في `app.template.html` وينتج `index.html`. |
| `mark.svg` | شعار الورقة، مستخرَج من ملف الهوية. |
| `lockup.svg` | الشعار الكامل (KIFFA + كِفّة)، غير مستخدَم في اللوحة — أصل احتياطي. |
| `*.woff2` | خطوط الهوية بعد التصغير: Frutiger LT Arabic (400/700/900) و Lato (400/900). |

## التعديل

عدّلي `app.template.html` ثم:

```bash
python3 /Users/dohaalhusyin/Downloads/kiffa-ideas/build.py
```

لا تُعدَّل `index.html` مباشرة — البناء يعيد كتابتها.

### تغيير الأسماء

في `app.template.html` ابحثي عن:

```js
var TEAM = ["منار","ميعاد","مي","جود","شهد","ضحى","ريما"];
```

### تغيير قيم النقاط

قيمتا 1 و 10 موجودتان في `value` لأزرار الاختيار داخل النافذة، وفي
`mkBtn(name, points)`.

## أين تُحفظ البيانات

كل شيء يُحفظ في `localStorage` على المتصفح نفسه، عبر الكائن `Store`
في أعلى السكربت (`read` / `write` فقط). هذا يعني:

- البيانات **لا تُشارَك بين الأجهزة**؛ كل جهاز له سجله الخاص.
- لجعلها مشتركة بين الفريق يكفي استبدال `Store` بطبقة تقرأ وتكتب من
  Supabase — نفس ما جرى في `kiffa-dashboard`. بقية الكود لا يتغيّر.
- إذا مُنع الحفظ (مثل فتح الملف مباشرة في بعض المتصفحات) تظهر لافتة
  تحذير أعلى الصفحة قبل تسجيل أي شيء.

## التقرير

زر «تصدير تقرير» ينتج ملف CSV بترميز UTF-8 يفتح في Excel مباشرة،
ويحتوي: ترويسة بالنطاق والفلترة، ثم جدول ترتيب النقاط لكل اسم، ثم
تفاصيل كل مشاركة. التصدير يتبع الفلترة المفعّلة وقت الضغط.
