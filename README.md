# لوحة الأفكار والمبادرات — كِفّة

لوحة مبسّطة لفريق التسويق في كِفّة للقهوة المختصة: تسجيل نقاط المشاركة
لكل موظفة، مع تفاصيل الفكرة وتاريخها، ترتيب مباشر للمتصدرات، فلترة
بالاسم وبالنطاق الزمني، وتصدير تقرير.

## الملفات

**الموقع:** https://dohahus.github.io/kiffa-ideas/
يُنشَر تلقائيًا من فرع `main` (GitHub Pages، مصدر الفرع مباشرة بلا workflow).

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة الموقع المنشورة (51 KB) — تربط الخطوط من `fonts/`. |
| `fonts/*.woff2` | خطوط الهوية بعد التصغير: Frutiger LT Arabic (400/700/900) و Lato (400/900). |
| `kiffa-offline.html` | نسخة مدمجة في ملف واحد تعمل بلا إنترنت — للاستخدام من الجهاز مباشرة. |
| `app.template.html` | المصدر الذي تُحرَّر فيه التعديلات. |
| `build.py` | يبني `index.html`، و`kiffa-offline.html` مع `--inline`. |
| `supabase/schema.sql` | جدول `ideas` وسياسات RLS. |
| `mark.svg` | شعار الورقة، مستخرَج من ملف الهوية. |
| `lockup.svg` | الشعار الكامل (KIFFA + كِفّة)، غير مستخدَم في اللوحة — أصل احتياطي. |

## التعديل

عدّلي `app.template.html` ثم:

```bash
python3 /Users/dohaalhusyin/Downloads/kiffa-ideas/build.py
```

لا تُعدَّل `index.html` مباشرة — البناء يعيد كتابتها.

### تغيير الأسماء

في `app.template.html` ابحثي عن:

```js
var TEAM = ["منار","ميعاد","مي","جود","شهد","ضحى","ريما"];
```

### تغيير قيم النقاط

قيمتا 1 و 10 موجودتان في `value` لأزرار الاختيار داخل النافذة، وفي
`mkBtn(name, points)`.

## أين تُحفظ البيانات

الكود جاهز للسجل المشترك، وينتظر قيمتين فقط. في أعلى السكربت داخل
`app.template.html`:

```js
var SUPABASE_URL      = "";
var SUPABASE_ANON_KEY = "";
```

**وهما فارغتان الآن**، فاللوحة تحفظ محليًا في المتصفح — كل جهاز له سجله.

### تشغيل السجل المشترك

1. في Supabase: افتحي **SQL Editor** والصقي `supabase/schema.sql` ثم **Run**.
2. من **Project Settings ← Data API** انسخي `Project URL` و `anon public key`.
3. الصقيهما في المتغيّرين أعلاه، ثم `python3 build.py`، ثم ادفعي التغيير.

مفتاح `anon` مُصمَّم ليكون ظاهرًا في المتصفح؛ الحماية من سياسات RLS.
**لا تضعي مفتاح `service_role` هنا إطلاقًا.**

### كيف تتصرّف اللوحة

- صف مستقل لكل مشاركة في جدول `ideas` — لا تضيع مشاركة لو سجّلت
  زميلتان في نفس اللحظة.
- الحفظ والحذف يظهران فورًا ثم يُراجَعان: لو فشل الطلب تتراجع اللوحة
  وتعرض سبب الفشل.
- `localStorage` صار نسخة احتياطية للعرض عند انقطاع الاتصال فقط، مع
  لافتة تنبيه واضحة أعلى الصفحة.
- السجل يُحدَّث تلقائيًا عند العودة إلى الصفحة، فتظهر مشاركات الزميلات.
